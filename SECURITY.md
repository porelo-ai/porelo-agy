# Security

Report a vulnerability in this package privately, through GitHub's **Report a vulnerability** under
this repository's **Security** tab, never in a public issue, a pull request or a discussion. A
problem in Antigravity CLI itself goes to its own maintainers; tell us too if Porelo makes it worse.
What happens then, what is in scope and how you are credited is on the project's page,
[Reporting a vulnerability](https://porelo-ai.github.io/porelo-project/security/).
